# Support

Need help with cola?

1. **Read the user guide** — [docs/user-guide.md](docs/user-guide.md) covers
   installation, configuration, every Feishu command, logs, and troubleshooting.
2. **Ask a usage question** — post in
   [Discussions](https://github.com/SXongin/cola/discussions) (Q&A). Issues are
   reserved for bugs and feature requests.
3. **Report a bug or request a feature** — use the issue forms; include your
   `cola --version` output and the relevant log excerpt, with secrets and
   personal data removed.
4. **Report a security vulnerability** — privately via
   [GitHub security advisories](https://github.com/SXongin/cola/security/advisories/new),
   never in a public issue (see [SECURITY.md](SECURITY.md)).

cola is a spare-time project, maintained on a best-effort basis.
